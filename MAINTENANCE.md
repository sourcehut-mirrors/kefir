# Maintenance policy

In accordance with the
[announcement](https://kefir.protopopov.lv/posts/announce2.html) (May 31, 2026),
active public development of Kefir C compiler has been shut down for an
indefinite period of time.

The publicly available portion of the code base remains accessible. Bug reports
are accepted against `v0.5.1` git tag and the head of the `master` branch via
the [mailing list](https://lists.sr.ht/~jprotopopov/public-inbox) or privately
[via email](mailto:jevgenij@protopopov.lv). Bug fixes, to the extent possible,
will be published on the `master` branch under the same license.
